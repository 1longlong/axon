# Axon v0.1.3

## 更新内容

- Pi Agent 支持会话级 Shell 环境异步预热与文件快照，匹配工作目录时恢复 PATH 等导出变量，减少工具调用重复读取启动配置。
- 快照采用私有权限与原子发布，会话删除、工作区变化和应用退出时释放，自动清理无归属及长期不活跃的遗留缓存。
- 修复 Pi 沙箱不可用时的原生工具回退：保护不可落实时明确拒绝运行，并保存可恢复的失败信息。
- 工具审批依据实际执行来源；Zima 的 Bash 和写入工具默认需要人工审批，同名自定义工具不会继承内置工具的自动放行权限。
- explore/plan 子 Agent 使用只读策略；仅实际只读沙箱覆盖时向 explore 提供 Bash，用户审批不能扩大角色权限。
- 改善 Shell 权限拒绝的目标路径识别，保留同次调用的精确文件/网络授权链路。
- 同步项目设计、通信协议示例与最新进度文档。

## 安装包与边界

- macOS Apple Silicon：`Axon-0.1.3-arm64.dmg`、`Axon-0.1.3-arm64.zip`，附 `SHA256SUMS.txt`。
- 当前为开发版本，未配置 Developer ID 签名与公证。
- Shell 初始化读取用户启动配置，不套模型工具沙箱；模型命令仍受 Seatbelt 限制。
- 普通 Shell 执行不保证终端 alias/函数跨 Shell 保留，单次 export/cd 不更新快照基线。
- Zima 仍需单独准备 Python 环境，不具备宿主 OS 沙箱与 Shell 快照能力。

## 验证

- 全仓 583 项测试通过，类型检查与 production build 通过。
- 真实 Electron/Seatbelt 冒烟覆盖环境恢复、只读写入拒绝、精确授权、停止和清理。
- 真实桌面冒烟覆盖权限卡、子 Agent、消息流与聚合会话恢复；模型事件使用隔离夹具，未连接外部模型 API。
