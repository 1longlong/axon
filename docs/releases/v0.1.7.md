# Axon v0.1.7

## 新增

- Pi Agent 分类附件：主窗和快捷浮窗支持选择、拖入和粘贴文件、文件夹与图片，文件/文件夹共用原生选择入口。
- 图片输入：准备后随请求交给支持图片的模型，提供能力确认、缩略图及完整预览；历史保留图片，暂停、压缩和重启不删除应用侧附件。
- 原生 PDF/DOCX Skills：随包提供 `pdf`、`documents` 指引，通过受审批与沙箱约束的 `axon-doc` 提取本地文档正文。
- 行内 Skill 胶囊：选择的 Skill 与文字同行，支持删除、撤销、排队及历史恢复，发送时后端核对来源并直接加载指引。
- 动态斜杠候选：输入 `/` 即在输入框上方展示命令和可用 Skill，继续输入实时筛选，方向键、Enter、Tab 或点击直接选择。`/skills` 保留完整选择器入口。

## 完善

- 长文本直接粘贴，超过阈值自动保存为文本附件，无需手动填写文件名或来源。
- 中立消息保存文字与 Skill 的真实顺序，排队、历史、复制、模型输入和有界恢复保持一致；恢复使用当时保存的指引，不重读新版 Skill 改写旧消息。
- 附件草稿、上传、预览和队列沿用原入口身份与租约校验；来源失效或准备失败阻止整条发送，不发送半份选择。
- 桌面构建按后端依赖清单复制运行资源，包含图片处理、文档命令和内置 Skills，不依赖开发目录遗留链接。

## 使用与限制

- 提供 macOS Apple Silicon（arm64）DMG、ZIP、独立 CLI 压缩包和 SHA-256 校验文件。
- macOS 应用尚未配置 Developer ID 签名与公证；独立 CLI 解压后需保留完整目录。
- 本次新增附件和斜杠交互仅用于 Pi Agent；Zima、Loop 和 CLI 附件输入未接入。
- PDF/DOCX 指引提供正文提取，不包含 OCR、Office 自动化、排版渲染或文档编辑。未引入插件体系或远程安装源，未修改 Pi SDK。

## 验证

- 全仓 1,540 通过、2 项需显式解释器的 Zima 专项跳过、0 失败；九 workspace 类型检查通过。
- Electron 源码与独立 CLI 构建通过；源码桌面实际验证图片请求、动态候选/直接插入 Skill、排队、文档沙箱、暂停继续、自动压缩及新进程恢复。
- DMG、ZIP、CLI 压缩包完整性和三份 SHA-256 校验通过；应用包版本为 0.1.7，文档命令、图片依赖与内置 Skill 资源齐全。
- 使用隔离临时目录和本机模型夹具，未对外部模型服务或安装后的 GUI、Keychain 做验收。
