# Axon UI 设计与实现

> 2026-10-14。本文描述当前界面和代码分工；整体架构与迭代范围见 [项目设计](axon-project-design.md)，验收状态与接续事项见 [当前进度](PROGRESS.md)。

## 视觉规则

Axon 使用浅色、极简、高密度的开发者工作台风格：细边框、小圆角、克制强调色、等宽技术标签。深色主题消费同一组语义 token，快捷浮窗保留自己的表面 token。

| 位置 | 当前规则 |
| --- | --- |
| 会话背景 | `--content-area`，浅色 `#FAFAFC` |
| 侧栏与工具轨 | `--sidebar-surface`，浅色 `#FBFBFC` |
| 输入、文件内容、弹层 | 白色表面；弹层按主题调整 |
| 次级表面 | `--muted`，浅色 `#F1F3F6` |
| 常规 / 弱分隔 | `--border` / `--border-subtle`，浅色 `#E8ECF1` / `#EEF1F5` |
| 正文 / 辅助文字 | 浅色 `#1E293B` / `#5F6D82`；辅助文字仍保持可读对比 |
| 强调色 | 靛蓝用于激活条、选中项和上下文圆环；琥珀色用于当前项目及目录 |
| 字体 | `--font-sans` 用于正文，`--font-mono` 用于代码、路径、模型和技术标签 |
| 密度 | 常见控件约 12px、技术标签约 11px；消息正文尊重用户字号设置 |
| 圆角与阴影 | 全局基础圆角 6px；输入容器局部 12px；阴影只提供轻微表面层级 |

字体栈优先使用已安装的 Inter / JetBrains Mono，然后回退系统字体；仓库没有打包这两种字体，也不加载在线字体。焦点提示使用独立 ring，不能以弱分隔线代替。

## 界面与交互

### 导航、顶栏与输入

- 左栏包含 Agent / Chat 切换、项目搜索、项目与会话树、设置入口。会话行不显示图标，当前 Agent 会话用 2px 左侧靛蓝激活条和背景标识；项目文件夹颜色表示当前会话所属项目。
- 会话顶栏展示真实标题、模型与项目信息；编辑标题、字号、创建/搜索/删除和 Runtime 选择沿用既有处理链。
- 普通发送为圆形上箭头，可访问名称为“发送消息”；Agent 运行控制复用同一按钮，Chat 保留停止入口，追问仍在输入区附近显示。
- Agent 批准策略由盾牌按钮打开菜单，选中项高亮。“请求批准”可用，“帮我批准”和“完全访问权限”保持禁用；菜单不增加策略写入或工具权限。
- 模型、思考强度、上下文用量和 Runtime 使用真实状态。终端和浏览器仍是未实现的占位面板。

### 消息与思考

- Agent 按中立 `SDKMessage` 聚合用户轮次和回复，保持工具调用、回传、正文及终态的原顺序。Chat 使用独立消息链，复用 Markdown、代码块和思考组件。
- 同轮相邻思考与工具调用跨模型请求归入连续活动组；非空正文是分组边界，空起始块/已关联工具回传/内部压缩终态不打断活动。进行中默认展开逐项显示，正文或普通完成/失败终态到达后默认收起为确定性计数摘要；用户可重新展开，后续片段不会重置手动选择。用户主动停止时尾组仅停止动画，保留原展开选择；重建后该中断尾组默认展开，其他失去活跃运行的历史尾组仍收起。
- 活动组收起只隐藏普通记录；失败/待审批/仍运行的工具、追问入口与独立子任务卡片继续可见，失败数量及待交互状态在摘要中标识。原审批/追问面板仍靠近输入区，参数和结果继续复用原工具详情；错误终态及权限拒绝不进入普通完成摘要。主会话/快捷浮窗和子任务详情共用轮内投影，原 JSONL 不重排、不增加字段。
- 消息在接近底部时跟随输出；用户查看历史时暂停跟随，可用“回到最新”恢复。工具展开详情按内容撑开，最高 224px，超出后内部滚动。
- Agent 主窗/浮窗重新聚焦读取历史时保留当前轮尚未落盘的流式草稿，无新片段也不会消失；读取中的撤回/重试仍生效，完整同 UUID 回复替换草稿，不复制旧缓存或重新发起生成。
- Agent 受控停止的部分输出以同一 UUID 检查点替换草稿，半截工具参数不恢复为调用。正常用户停止不额外显示“已停止 / Agent 执行已停止”错误卡，也不产生空回复占位；停止 result 仍保存在历史用于状态判定。真实清理/存储/运行失败继续显示。未收到真实回传的工具显示“结果未知”，在收起的活动组中仍可见，不显示成功勾选或计为确定失败；详情说明需核实实际副作用。
- Agent 主输入区和快捷胶囊共用暂停/继续控制。主输入区只保留原发送位置的圆形图标按钮：空闲为发送箭头，原入口运行中为暂停，暂停完成且空草稿为继续；输入新消息时恢复发送箭头，不额外添加暂停/继续或排队按钮，运行中 Enter 仍可排队。收束/继续提交显示禁用加载图标，读取失败在同位置提供只读重查；图标保留 aria-label/title，浮窗暂停/继续也只显示图标。
- 原入口运行中提交新消息默认进入后端队列，主输入上方显示单行消息胶囊，快捷浮窗展开时共用该组件。多条按队列顺序横排，溢出横向滚动，长内容截断并保留完整悬停提示；每条可取消，不显示排序按钮或额外排队按钮。正常轮次结束后后端自动取下一条，离队时才进入用户历史并启动新轮；不把等待消息伪装成已发送消息，也不由 UI 重发。暂停仍按原策略清空等待队列。
- 观察入口不获得控制权；正在暂停禁用重复控制/发送/配置，权威 paused 且重读成功后才开放继续。交付未知不自动重发；继续不新增用户消息，按系统继续标记的原 turn_id 和停止结果 UUID 合并原回复，真实执行仍用新 runId 隔离旧控制。运行中不再显示旧执行尾部时间，完成后只有一个时间/复制栏；文件变更和 Skill 使用汇总包含中断前后。后台文本输入不显示气泡，但保留自身 UUID 供暂停后同轮合并。新输入另起一轮，错误和未知工具状态不隐藏；浮窗立即上拉，Chat 停止不变。本次源码桌面复验双入口/新 PID 恢复和唯一回复时间通过；GUI 模型事件为中立夹具，Pi/Zima 的真实 Runtime 链另行验证，不宣称为外部模型 GUI 验收。
- `ThinkingBlock` 默认折叠，历史思考展开从顶部阅读；长内容最高 150px，仅被裁切的边缘淡出。生成中只有用户停在底部才跟随，上翻后暂停；收起或卸载释放 ResizeObserver。
- 当前未完成回复有非空思考、正文、工具或权限拒绝输出后，隐藏重复的通用 Agent 等待动效；各内容块、重试和压缩自己的状态仍保留。

### 文件工作区

- 右栏无文件时只保留 44px 工具轨。点击文件图标独立打开透明文件树气泡，尖角指向入口，浮在文件内容之上；主题表面透明度为 72%，背景模糊 2px，减少透明度偏好下使用实色。
- Escape、关闭按钮和入口切换只收树并归还焦点；外部点击只收树、不抢目标焦点。工作区保持挂载，目录展开态、监听和已打开内容保留。
- 每个文件是一个 Tab，相对路径去重；标题栏只展示文件名与关闭入口，没有文件图标、大小、只读标记或装饰边框。长名称截断并提供完整路径提示。
- 标签支持左右键、Home/End 和 Delete。关闭当前项选择左邻或首个剩余项；关闭最后一个文件自动收栏，焦点回到文件图标。
- 内容独立缓存并保持各自滚动容器。目录变化刷新所有已打开文件而不切换选择；工作区切换清空 Tab；标签只保留在会话视图内存中，不持久化。
- 右栏默认 240px，最小 220px，最大 600px；实际扩展还扣除左栏、480px 会话预留、工具轨和缩放条。只有前台会话同步共享收栏状态，后台空会话不能覆盖当前布局；后台记忆编辑器保留草稿。
- 文件树使用 `@react-symbols/icons` 的 `FileIcon autoAssign` 按文件名分配图标；未知类型回退默认图标。目录使用统一琥珀色文件夹，符号链接保持不可预览边界。
- 预览保持只读，复用 Shiki；当前源码、语言与主题匹配后才展示高亮，等待期间先显示当前纯文本。保留文件末尾换行和真实行号、512 KB 上限、二进制提示及主进程路径安全校验。

### 设置与弹窗

设置框架、用户资料、外观、渠道、模型编辑、Agent / Skills，以及项目、MCP、任务、权限和追问弹窗共用语义表面、细边框和紧凑控件。技术 ID、URL、JSON 和计数使用等宽字体。保存、失败回滚、未保存退出保护、审批范围和任务消息聚合继续使用现有业务契约。

## 代码分工

以下路径以 `apps/electron/src/renderer/` 为根。

| 入口 | 职责 |
| --- | --- |
| `styles/globals.css` / `../../tailwind.config.js` | 主题、字体、圆角、阴影及气泡/思考局部样式 |
| `components/icons/WorkbenchIcons.tsx` | 实际使用的静态工作台 SVG；不承担状态 |
| `components/app-shell/LeftSidebar.tsx` | 项目与会话导航、激活状态及左栏宽度 |
| `components/agent/AgentMessages.tsx` / `lib/agent-turn-groups.ts` | Agent 轮次呈现、等待提示和阅读跟随 |
| `components/agent/AgentMessageItem.tsx` / `lib/agent-activity-groups.ts` | 轮内正文/活动投影、计数摘要、展开收束与异常可见性 |
| `components/chat/ThinkingBlock.tsx` | Agent / Chat 共用思考折叠与阅读行为 |
| `components/agent/AgentPermissionMenu.tsx` | 批准策略图标菜单与可用能力说明 |
| `atoms/panel-layout.ts` / `components/agent/AgentSidePanel.tsx` | 布局范围、前台身份、文件气泡入口及收栏协调 |
| `components/agent/WorkspaceFileTree.tsx` | 目录读取、监听、文件选择及请求生命周期 |
| `components/agent/WorkspaceFileTabs.tsx` | 标签、键盘/焦点与只读内容呈现 |
| `lib/workspace-file-tabs.ts` | 路径去重、选择/关闭与异步结果状态迁移 |
| `components/chat/ShikiCodeBlock.tsx` | 消息代码块与工作区只读源码两种呈现 |
| `components/settings/` | 原有设置表单与保存边界 |

文件链路：文件选择 → controller `readProjectFile` → 既有 preload / main 安全读取 → reducer 按路径与请求编号接收 → Tab 内容渲染。监听刷新复用同一读取链；工作区版本与请求编号共同丢弃迟到结果，关闭后不能被后台刷新重新打开。

UI 不 import Runtime SDK，不绕过 IPC 读文件，也不增加存储字段。新增的 `@react-symbols/icons@1.4.1` 自动映射带入图标集；此前测量 AgentViewShell gzip 从 20.58 kB 增到 171.09 kB，约增加 150.51 kB。保留既有 Vite 大 chunk 提示，性能专项暂不实施。

## 验证

- 自动化重点：消息轮次与等待状态、布局限宽、路径去重、多文件乱序/迟到结果、刷新/关闭/重开、单文件错误隔离、源码转义及二进制/大小边界。
- Electron 冒烟入口：`apps/electron/scripts/smoke-agent.ts`，使用隔离工作区与中立事件夹具检查 UI、监听、权限、流式阅读和恢复；按钮按当前可访问名称定位，预览按可见节点定位。
- 真实窗口已经检查浅色导航、输入、思考折叠、文件气泡、Tab 切换/关闭/阅读位置、侧栏扩展，以及部分设置与项目/MCP 弹窗。未完成的动态边界集中记录在 [当前进度](PROGRESS.md)，不把脚本打包或静态渲染记为 Electron 冒烟通过。
