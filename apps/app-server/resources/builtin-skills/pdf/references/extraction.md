# PDF 范围与结果

- 命令只读本地普通文件，输入不超过 20 MiB；不下载外部链接，不执行嵌入脚本。
- `--start`、`--end` 是页码，默认从第 1 页读取 20 页；每次最多 1000 页。
- `--max-chars` 限制返回正文，默认 20000，最多 100000；JSON 会标识截断，不会假装全文已读取。
- `totalSections` 是 PDF 总页数。每个 `sections` 项包含 `number`、`kind: "page"` 和 `text`。
- 文档损坏、加密、读取权限不足或页面解析失败时，命令非零退出。先检查错误和路径，不自动安装依赖、取消沙箱或反复执行相同命令。
- 图像、扫描页和布局不是文字提取结果；不能仅凭文字结果确认视觉排版。
