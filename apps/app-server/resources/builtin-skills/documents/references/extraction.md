# DOCX 范围与结果

- 输入必须是 20 MiB 以内的本地 DOCX 普通文件。附件选择并不授权修改或执行文档。
- `--start`、`--end` 指提取段落/表格行的序号，而非页码；默认读取前 20 项，每次最多 1000 项。
- 正文默认上限 20000 字符，可用 `--max-chars` 调整至最多 100000；截断时需明确告知，不能把预览当全文。
- 表格保留行内单元格文字，但不承诺列宽、合并、分页或嵌套关系的完整还原。
- 文档图片、绘图、版面和宏不会执行或渲染。需要这些能力时直接说明当前限制。
- 解析失败时先核对文件路径、格式、权限或加密情况，不自动下载安装环境，也不请求绕过沙箱来“修复”格式错误。
